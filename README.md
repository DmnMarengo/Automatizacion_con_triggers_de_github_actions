# Trabajo Práctico GitHub Actions

## Nombre:
Damian Marengo

## Descripción

Este repositorio contiene 6 workflows de GitHub Actions utilizando distintos triggers:

1. push → se ejecuta al hacer push a main.
2. pull_request → se ejecuta al abrir PR.
3. issues → se ejecuta al crear issue.
4. issue_comment → se ejecuta al comentar en PR.
5. workflow_dispatch → ejecución manual con input choice.
6. schedule → ejecución automática cada hora.
